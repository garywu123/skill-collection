# Microsoft 365 Reference

Microsoft 365 Copilot is reached through the `m365-copilot-web` MCP server,
which drives its own tab in the user's signed-in Copilot web page.

## Connect

1. Call `copilot_status`. If `chromeRunning` is false, call it again with
   `launch: true`.
2. If `signedIn` is false, ask the user to finish signing in in the Chrome
   window, then check again. Never type or request credentials.

## Conversation modes

| Mode | Use when | `session` value |
|---|---|---|
| Ask | A one-off question | `"new"` |
| Chat | Follow-ups or revisions on one subject | A short kebab-case name, such as the topic; reuse it later |
| Continue | Continue the connector's last conversation | `"current"` |

Call `copilot_sessions` to list saved chat names before inventing one.

## Synthesis prompt

Write the prompt in the user's language and adapt the parts to the route:

```text
Answer in <language>. No preamble or role statement. Keep it under <N>
characters.
<If a file is attached:> The attached file contains Confluence pages and Jira
issues exported on <date>. Treat it as the authoritative source for <product
definition | ticket status>. When you use a section, cite the URL on its Link
line, not the file.
1) <first part of the question, with identifiers>
2) <second part: search my Microsoft 365 meetings, chats, mail, and files for
   ..., with dates, decisions, and action items>
Label each point [Confluence], [Jira], or [M365]. List conflicts and outdated
copies separately. End with a source table: title, system, date, link.
```

Use about 3000 characters for a normal question; Copilot may be fuller than
the brief, because the brief is condensed afterwards. Longer answers often
exceed the inline tool-result limit, especially in Chinese.

## Call and result

- `copilot_ask` with `session`, `attachments` (absolute paths), and
  `timeoutSeconds` (default for questions, 600 for document generation).
  Attach only exported context or files the user named; uploads are stored in
  the user's OneDrive as Copilot chat files.
- The result has `answer` (Markdown), `files`, `conversationId`, `url` (the
  conversation link to give the user), and `complete`. `files` holds at most
  `maxFiles` (default 10), generated documents first; `filesTotal` appears
  when the list was capped. `files[].sources` is `file-card`, `citation`, or
  `generated`.
- If the tool result is saved to a file because it is too large, read it once
  with PowerShell, for example
  `(Get-Content -Raw '<file>' | ConvertFrom-Json)`, selecting `answer`,
  `files`, and `url`; do not try to view the whole file.
- When `complete` is false, call `copilot_read` with the returned
  `conversationId` or session name until it completes or the user stops.
- If Copilot reports a failure, report it and offer one retry.
